# قراردادهای آیندهٔ backend (غیرفعال در نسخه محلی)

این سند مرز امنیتی قابلیت‌هایی را مشخص می‌کند که تا زمان وجود backend امن نباید به‌صورت صوری در APK فعال شوند. همهٔ feature flagهای این بخش در کلاینت به‌طور پیش‌فرض `false` هستند.

## حساب و احراز وکیل

- وضعیت: `unverified | pending | verified | rejected`
- تأیید ساختاری کد ملی و موبایل در دستگاه انجام می‌شود؛ احراز هویت، مالکیت موبایل و اعتبار پروانه فقط با API رسمی/فرایند انسانی معتبر.
- هیچ داده پرونده، موکل، سند یا یادداشت بدون رضایت صریح و عملیات قابل مشاهده کاربر ارسال نمی‌شود.

## Trial و entitlement

- `POST /v1/trials`: مدت پیش‌فرض پیشنهادی ۷ روز، ولی مدت مؤثر فقط از پاسخ امضاشده سرور.
- `POST /v1/licenses/restore`: بازیابی entitlement با token کوتاه‌عمر و پاسخ امضاشده.
- وضعیت: `trial | active | expired | suspended` با `startsAt`, `expiresAt`, `devicePolicy`.
- callback محلی پرداخت، boolean محلی و secret داخل APK معیار فعال‌سازی نیستند.

## به‌روزرسانی امن

- `GET /v1/android/update-manifest` فقط HTTPS معتبر.
- manifest شامل `versionCode`, `versionName`, `publishedAt`, `changelog`, `apkUrl`, `sha256`, `signature`.
- کلاینت checksum و امضای manifest را کنترل می‌کند و فقط installer استاندارد Android را با تأیید کاربر باز می‌کند؛ silent install ممنوع است.

## اعلان مدیریتی

- `GET /v1/notices?cursor=...` و push token ثبت‌شده با رضایت کاربر.
- دامنه مخاطب (`all | cohort | account`) فقط سمت سرور کنترل می‌شود.
- تا زمان وجود backend، UI وضعیت «در دست توسعه و غیرفعال» نمایش می‌دهد و پیام جعلی تولید نمی‌کند.

## قوانین و آرای وحدت رویه

- Source of Truth: API رسمی `kamranvahdati.ir`.
- endpointهای پیشنهادی: taxonomy، manifest نسخه داده، مجموعه‌ها، قوانین، مواد و آراء.
- بسته آفلاین باید checksum، نسخه taxonomy و نسخه محتوا داشته باشد. جست‌وجوی محلی فقط روی بسته تأییدشده دانلودشده انجام می‌شود؛ scraping مستقیم منابع اینترنتی در اپ ممنوع است.

## پروفایل عمومی وکیل

- انتشار کاملاً opt-in و جدا از داده خصوصی دفتر است.
- payload فقط شامل فیلدهای عمومی انتخاب‌شده کاربر است و هرگز شناسه پرونده، موکل یا اسناد را شامل نمی‌شود.
